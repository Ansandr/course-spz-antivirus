#### 16. `quarantine_json.png`

* **Інтерфейс:** Провідник Windows (File Explorer) + Зовнішній редактор (Sublime Text)
* **Стан / Контекст:** Технічна реалізація збереження метаданих карантину.
* **Ключові візуальні елементи:** Провідник показує вміст системної папки `AntivirusMVP > Quarantine`, де лежить зашифрований/переміщений файл `eicar.com_...txt` та файл `quarantine_index.json`. У текстовому редакторі відкрито JSON-файл, який містить масив об'єктів з метаданими ізольованого файлу (дата, ім'я, оригінальний шлях, шлях у карантині, назва загрози).
* **Рекомендоване місце в документі:** Розділ "Технічна документація: Архітектура модуля карантину" або "Структура збереження даних (JSON)".
