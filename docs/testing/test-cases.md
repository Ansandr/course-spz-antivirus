## Тест-план

### Мета
Перевірити відповідність реалізованого ПЗ функціональним вимогам ВР1–ВР7, задокументованим у розділі 2.1.4 пояснювальної записки.

### Методи тестування
| Рівень | Метод | Охоплені вимоги |
|--------|-------|----------------|
| Unit   | Qt Test | `SignatureDB`, `Scanner`, `Quarantine` |
| Integration | Ручне тестування GUI | ВР1–ВР7 |
| Regression | Повторний запуск після виправлення дефектів | ВР1, ВР2 |

### Тестові дані
- `eicar_test.txt` — файл з EICAR-рядком у тимчасовій директорії
- `signatures.db` — містить `44d88612fea8a8f36de82e1278abb02f  EICAR-Standard-Test-File`
- `whitelist.txt` — містить один шлях для перевірки виключень

### TC-01 — ВР1: Сканування директорії з виявленням EICAR

**Вимога:** ВР1-Сканування  
**Пріоритет:** Критичний  
**Передумови:**
- Програма зібрана та запущена
- `signatures.db` містить хеш EICAR
- Файл `eicar_test.txt` збережений у `C:\Temp\test_scan\`

**Кроки відтворення:**
1. Запустити `AntivirusMVP.exe`
2. На вкладці «Сканування» натиснути «Обрати…»
3. Обрати директорію `C:\Temp\test_scan\`
4. Натиснути «▶ Розпочати сканування»
5. Дочекатися завершення (кнопка «Зупинити» деактивується)

**Очікувана поведінка:**
- `QProgressBar` заповнюється від 0 до 100%
- У таблиці з'являється рядок: `C:\Temp\test_scan\eicar_test.txt | ⚠ Загроза | EICAR-Standard-Test-File`
- Рядок підсвічений червоним
- Статусний рядок: «Завершено. Перевірено: 1  Загроз: 1»

**Фактична поведінка:** _(заповнити після тесту)_  
**Результат:** ✅ Пройдено / ❌ Провалено

### TC-04 — ВР2: Ізоляція виявленого файлу до карантину

**Вимога:** ВР2-Карантин  
**Пріоритет:** Критичний  
**Передумови:** TC-01 пройдено; `eicar_test.txt` ще не ізольований

**Кроки відтворення:**

**Очікувана поведінка:**
- `QMessageBox` з'являється із запитом на ізоляцію
- Файл `eicar_test.txt` більше не існує у `C:\Temp\test_scan\`
- У вкладці «Карантин» з'являється запис: `eicar_test.txt | EICAR-Standard-Test-File | C:\Temp\test_scan\eicar_test.txt | <дата>`
- Файл присутній у `%APPDATA%\AntivirusMVP\Quarantine\`

**Фактична поведінка:** _(заповнити після тесту)_
