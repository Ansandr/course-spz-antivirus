- Файл присутній у `%APPDATA%\AntivirusMVP\Quarantine\`

**Фактична поведінка:** збігається з очікуваною; діалог з'являється, файл переноситься до карантину

## BUG-01 — Не з'являється діалог ізоляції загрози (блокує карантин)

**Статус:** Виправлено та перевірено 2026-06-11

**Тип:** Bug  
**Пріоритет:** Critical  
**Вимога:** ВР2-Карантин

**Очікувана поведінка:**
Після виявлення загрози під час сканування з'являється діалог «Загроза виявлена» з підтвердженням ізоляції. Після натискання Yes файл переноситься до карантину.

**Фактична поведінка до виправлення:**
Діалог «Загроза виявлена» не з'являється. Ізоляція не виконується, відновлення з карантину (TC-05) неможливе.

**Кроки відтворення:**
1. Запустити `AntivirusMVP.exe`.
2. На вкладці «Сканування» обрати директорію з `eicar.com.txt`.
3. Натиснути «▶ Розпочати сканування» та дочекатися виявлення загрози.
4. Переконатися, що діалог ізоляції не з'являється.

**Середовище:**
- OS: Windows 11 22H2
- Build: AntivirusMVP v1.0.0
- Qt: 6.6
- Toolchain: MSVC 2022, CMake 3.28

**Пов'язані тести:**
- TC-04: ✅ Пройдено після виправлення
- TC-05: ✅ Пройдено після виправлення

**Скріншот / лог:**
Додати скрін екрану результатів сканування без появи діалогу та витяг із `antivirus.log` за час запуску TC-04.

